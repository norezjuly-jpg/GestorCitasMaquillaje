API Web desarrollada en .NET 8 C# para la gestión de clientes, maquillistas, servicios y citas en un centro de belleza.

## 🚀 Tecnologías Utilizadas
- .NET 8 Web API
- C#
- Swagger / OpenAPI
- Git & GitHub (Flujo de ramas GitFlow: main, develop, feature branches)

## 📌 Funcionalidades Principales
- **Clientes:** Registro y consulta de información de clientes.
- **Maquillistas:** Gestión de personal y disponibilidad.
- **Servicios:** Catálogo de servicios de maquillaje con sus duraciones y costos.
- **Citas:** Programación y seguimiento del estado de citas.
